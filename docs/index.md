# VoraData — Docs

> Arquitectura, flujos SDD, presets y normas técnicas.

---

## Qué encontrarás aquí

- **SDD** — Flujo Spec-Driven Development para landing pages y aplicaciones Symfony
- **Presets** — Design system Tailwind, componentes y normas técnicas reutilizables
- **IA & Herramientas** — Configuración del DGX Spark, OpenCode y flujos agnósticos

## Stack

| Capa | Tecnología |
|---|---|
| Frontend | Vanilla JS + HTML + Tailwind CSS |
| Backend | Symfony (PHP) |
| IA local | DGX Spark + OpenCode |
| Docs | MkDocs + Material |

## Principio fundamental

Todo lo que se construye aquí es **agnóstico a la herramienta**. Funciona con cualquier LLM — local (DGX Spark) o cloud.
