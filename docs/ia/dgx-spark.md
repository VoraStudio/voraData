# DGX Spark

> Servidor IA local de VoraData. Potencia los flujos SDD sin enviar datos a la nube.

## Qué es

El NVIDIA DGX Spark es el servidor de inferencia local de VoraData. Permite ejecutar LLMs grandes con GPU propia, manteniendo los datos de clientes dentro del entorno controlado.

## Por qué local

- Datos de clientes no salen de VoraData
- Sin costes de API por token
- Latencia baja para sesiones largas de SDD
- Cumplimiento LOPD sin depender de terceros
